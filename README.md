# ORNAMENTAL GENOME AI V5

Версия использует 21 мотив, выделенный из загруженного пользователем листа казахских орнаментов.

## Есть в версии
- 21 базовый мотив в `assets/motifs/`;
- цветовые палитры и композиции;
- 12 вариантов поколения;
- пользовательский отбор;
- crossover + mutation;
- анимированный процесс эволюции;
- Ornament DNA;
- скачивание PNG;
- библиотека мотивов;
- Research Lab: GA vs Random.

## Важно
Часть названий мотивов пока рабочая. Для финальной конкурсной версии нужно сверить академические названия и происхождение каждого мотива.

Загрузите `app.py`, `requirements.txt`, `README.md` и папку `assets` целиком.
