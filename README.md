# ORNAMENTAL GENOME AI

## Запуск
1. Установите Python 3.10+.
2. Откройте папку проекта в терминале.
3. Выполните:
   pip install -r requirements.txt
4. Запустите:
   streamlit run app.py

Приложение откроется в браузере.

## Что реализовано
- цифровой «орнаментальный геном» из 9 генов;
- библиотека трёх стилизованных базовых мотивов;
- линейная, зеркальная, центральная и радиальная симметрия;
- генетический алгоритм: популяция, турнирный отбор, скрещивание, мутация, элитизм;
- многокритериальная fitness-функция;
- визуализация первого, промежуточного и последнего поколения;
- график изменения fitness;
- сравнение случайной и эволюционной генерации;
- модуль машинного обучения Random Forest, обучаемый на экспертных оценках пользователя.

Важно: мотивы в текущей версии являются алгоритмически стилизованными,
а не заявляются как точные этнографические копии традиционных образцов.
Для финальной конкурсной версии библиотеку мотивов рекомендуется расширить
по проверенным источникам и с консультацией специалиста по казахскому орнаменту.
