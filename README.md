# ORNAMENTAL GENOME AI 2.0

Обновлённая конкурсная версия.

## Что изменено
- 13 параметрических мотивов вместо 3 условных фигур;
- 4 категории: зооморфные, растительные, геометрические, космогонические;
- 4 композиционных режима;
- более понятная схема обучения Random Forest;
- экспертная разметка по трём критериям;
- экспорт обучающей выборки и результатов эксперимента.

## Как обновить сайт
В GitHub замените старые `app.py`, `requirements.txt`, `README.md` файлами из этого архива.
После Commit Streamlit Community Cloud обычно сам перезапускает приложение.

Важно: контуры — авторские стилизованные математические модели, не точные музейные копии.
