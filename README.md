# ORNAMENTAL GENOME — AI ETHNO DESIGN LAB (V3 MVP)

Конкурсный прототип для проекта «Орнаментальный геном».

## Есть в этой версии
- регистрация / вход + гостевой режим;
- Design Studio;
- стартовое поколение из 8 вариантов;
- пользовательский отбор;
- crossover + mutation;
- Ornament DNA;
- персональный AI Design DNA на RandomForest после 8+ оценок;
- My Studio;
- библиотека мотивов;
- Research Lab: GA vs Random;
- скачивание SVG и PNG;
- SQLite для демонстрационного аккаунта.

## Запуск
```bash
pip install -r requirements.txt
streamlit run app.py
```

## GitHub + Streamlit
Загрузите `app.py`, `requirements.txt` и `README.md` в ваш репозиторий. После commit Streamlit обычно перезапускает приложение автоматически.

## Важно про аккаунты
SQLite — только конкурсный MVP. Для настоящего публичного сервиса следующий шаг: Supabase Auth + Postgres + Storage, чтобы аккаунты и библиотека проектов не терялись при перезапусках облачного контейнера.

## Культурная корректность
Встроенные мотивы — авторские стилизованные параметрические модели для демонстрации алгоритма. Финальная конкурсная версия должна использовать собственные векторизации документированных источников и паспорт происхождения каждого мотива.
